# Platformer Game Project

## About

Platformer Game Project part of the [Introduction to Godot Youtube Course](https://www.youtube.com/watch?v=TLG2yVpLDT8) by ClearCode. \
The goal of this project is to learn Godot Engine while building a Metroid-style Platformer Game.

## Result

The result can be downloaded and played from [PlatformerGame.zip](https://github.com/matteoWorks/learningRepository/blob/main/Introduction%20to%20Godot%20by%20ClearCode/PlatformerGame.zip).
