# Youtube Course: Introduction to Godot by ClearCode

## About

Decided to follow the [Introduction to Godot Youtube Course](https://www.youtube.com/watch?v=TLG2yVpLDT8) by ClearCode, in order to start learning Godot's engine. \
The [Udemy Course](https://www.udemy.com/course/learn-to-code-by-making-games-in-godot/) is also available.
