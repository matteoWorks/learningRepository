# LLM Project

## About

LLM Project part of the [AI A-Z 2026 Udemy Course](https://www.udemy.com/course/artificial-intelligence-az/?couponCode=MT260504JP). \
The goal of this project is to fine-tune [this](https://huggingface.co/aboonaji/llama2finetune-v2#model-trained-using-autotrain) pre-trained model from [Hugging Face](https://huggingface.co/) on [this](https://huggingface.co/datasets/gamino/wiki_medical_terms) detailed medical terminology dataset.
